# 反馈管理与自动回执交互原型

在线预览：https://zanehawkelin-lang.github.io/drama-statistics-review/feedback-management/

沿用 DramaVideo Backend 现有蓝白后台样式。按照本次确认，所有反馈、客服邮箱与回执文案统一管理，不包含应用维度。

## 体验入口

- **反馈设置 / 自动回执**：开关、发件人、主题、正文、反馈编号变量、实时预览、测试发送、保存与取消。
- **反馈设置 / 邮箱接入**：模拟连接 Gmail、收件同步范围、同步开关、连接检查、历史邮件导入。
- **演示新反馈**：H5 首次提交、邮箱首次来信、用户补充邮件、Gmail 人工回复、发送失败、对方自动回复、连接失效。
- **处理 / 查看**：原始反馈、独立的自动回执、人工回复、用户补充及发送结果；支持失败重试和关闭后重新打开。
- 支持来源、用户 ID、邮箱、类型、状态与日期筛选、空结果、分页、当前筛选结果 CSV 导出。

## 已体现的规则

- 自动回执不改变反馈处理状态，不覆盖最新人工回复。
- 同一会话的后续邮件追加至原反馈，不新增反馈、不重复回执。
- 直接来信可无用户 ID，不根据邮箱自动认定用户身份。
- 历史导入、无效邮箱、缺少邮箱、对方自动回复不触发回执。
- 断线时阻止来信同步与邮件发送，H5 提交仍保留反馈。
- 每条反馈最多成功发送一次自动回执；失败重试保留原失败记录。

## 原型边界

所有数据、邮箱、邮件收发、授权、同步与处理结果均为演示。没有真实 Gmail 连接、网络发信或业务后台写入。设置与操作结果只保存在当前浏览器，可通过右上角「原型使用说明 → 恢复演示数据」重置。

图片仅模拟附件记录及示例预览，不会上传。正式接入需要研发核实既有邮件服务、Gmail 授权及会话关联链路。

## 本地预览

从仓库根目录启动任意静态服务器，访问 `/feedback-management/`。页面使用原生 HTML、CSS、JavaScript，无构建依赖。
