# 自动续费看板原型

## 已确认
- 独立页面，入口位于订单管理的“订单日报”下方。
- 同时查看续费计划与自动续费交易，分开展示。
- 沿用现有 DramaVideo 后台样式和现有 GitHub 仓库，保留订单列表原型。

## 本版讨论稿
- 续费计划按订阅展示下次扣款、计划金额、订阅状态、续费状态及渠道。
- 续费记录按单次扣款尝试展示成功、失败、处理中和失败原因；同一订阅可多次尝试。
- 计划金额与实际收款分开；交易成功率按已结束尝试计算，处理中不参与分母。
- 仅演示查询、排序、详情、关联记录、分页和导出，不发起扣款或修改订阅。
- 所有数据均为 DEMO 模拟数据。订阅状态枚举、重试策略及真实接口字段仍需结合正式后台评审。

## 核对
- 两类列表独立筛选，切换页签不混淆时间含义。
- 重试失败后成功仅将成功记录计入收款金额；不将计划金额当收入。
- 订单原型新增可访问入口，新页面可返回订单列表。
